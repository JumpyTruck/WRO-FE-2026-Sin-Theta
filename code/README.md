# Code Directory

Welcome to the main code repository for the WRO Future Engineers team. This directory houses all scripts, test suites, and configurations required for running the robot across different stages of the competition.

---

## Directory Structure

| Folder / File | Description |
| :--- | :--- |
| **[Random Combination Generator](Random%20Combination%20Generator/)** | Contains utility code and scripts for generating random combinations (e.g., parking, run setups, or challenge variations). |
| **[Serial Test Code](Serial%20Test%20Code/)** | Dedicated code, configuration files, and testing documentation for validating hardware and serial communication modules. |
| **[internationals](internationals/)** | Advanced algorithms, finely tuned routines, and source code prepared specifically for international-level rounds. |
| **[md](md/)** | Documentation and markdown setup guides, including hardware assembly and configuration steps like the [raspberrypi_setup.md](md/raspberrypi_setup.md) guide. |
| **[nationals](nationals/)** | Competition code and scripts tailored and used for the national-level rounds. |
| **[labadjuster.py](labadjuster.py)** | A standalone calibration and tuning script used for quick adjustments during testing sessions in the lab. |

---

## Quick Navigation & Setup

* **Hardware & System Setup:** For environment configurations, refer to the guides available inside the [md](md/) folder.
* **Testing Hardware:** Before deploying run code, verify sensor and microcontroller connections using the tools in [Serial Test Code](Serial%20Test%20Code/).
